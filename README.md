# Vvveracruz Tap

## How do I install these formulae?

`brew install vvveracruz/tap/<formula>`

Or `brew tap vvveracruz/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "vvveracruz/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
